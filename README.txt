NITYU.RU — временная страница

Файлы:
- index.html — весь сайт
- favicon.svg — иконка вкладки
- CNAME — домен для GitHub Pages
- .nojekyll — отключает обработку Jekyll

Для локального просмотра:
просто откройте index.html двойным кликом.

Для публикации через GitHub Pages:
1. Создайте публичный репозиторий.
2. Загрузите в корень все файлы из этой папки.
3. Settings → Pages → Deploy from a branch → main / root.
4. В Custom domain укажите nityu.ru.
5. В DNS REG.RU направьте домен на GitHub Pages.
